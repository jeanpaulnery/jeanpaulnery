## Jean Paul Nery

Computational and theoretical physicist (PhD). Currently a Marie Curie Fellow
at the University of Liège, working on electron-phonon interactions from first
principles — deriving the theory, implementing it in Python and Fortran, and
running large-scale simulations on HPC clusters.

Moving to London and open to industry roles from September/October 2026
(right to work in the UK).

Most of my work so far has been research code written alongside publications.
The repositories below are two typical examples.

- **npgreen** — Python package that builds the electronic Green's function and
  spectral function from first-principles supercell calculations with distorted
  atomic configurations (for example, sampled stochastically from the quantum
  phonon distribution at finite temperature), rather than from perturbation
  theory. Reads wavefunctions and eigenvalues from ABINIT and handles the
  unfolding from supercell to primitive cell.
- **forbidden_reflection** — Fortran code for the temperature dependence of the
  valence charge density and of the resulting structure factors, derived and
  implemented perturbatively, taking wavefunctions and energies from
  first-principles calculations as input. Applies to symmetry-forbidden X-ray
  reflections in any material.
